# TRADEPORT — Static Demo (GitHub Pages)

**公開URL: https://jiantailanglin266-rgb.github.io/tradeport-demo/**

グローバル金融ポータル「TRADEPORT」（FX・CFD・株式・自動売買EA・海外ブローカー比較）の
**静的エクスポート版**です。デザイン・多言語構造・SEO実装を実URLで確認するための公開デモです。

このリポジトリは `next build`（`output: export`）の出力を配置したもので、ソースコードは別リポジトリ（Private）にあります。
再生成は本体側の `node scripts/build-static-demo.mjs` で行います。

## 静的版で動くもの・動かないもの

**動く**: 全ページ表示・8言語切替・クライアント側ページ遷移・EA一覧フィルタ・ブローカー比較表（差分ハイライト）・
ヒーローのcanvas演出・スクロール連動アニメーション・レスポンシブ

**動かない（サーバーが必要）**:

| 機能 | 静的版の挙動 | サーバー版 |
|---|---|---|
| IB クリック計測 | 提携先へ直リンク（計測なし） | `/go/[broker]?source=` で流入元・キャンペーン・デバイス等を記録して302 |
| ニュースレター登録 | 「送信も保存もしません」と表示 | `/api/newsletter`（Zod検証・重複判定） |
| ルート `/` の言語振り分け | meta refresh で `/en/` へ | proxy によるルーティング |
| 会員登録・EAダウンロード | 未実装（Phase 3） | Supabase Auth＋署名付きURL |

## 注意

掲載しているブローカー・EA・市場データ・統計は**すべてデザイン確認用のサンプルデータ**であり、
実在の企業・商品・価格を示すものではありません。

本サイトの内容は一般的な教育情報であり、投資助言ではありません。
レバレッジ取引は元本を超える損失を含む高いリスクを伴い、過去の成績（バックテストを含む）は将来の結果を保証しません。
