戦略概要

Meridian Swingは上位足の構造ブレイク＋リテスト確認でエントリーし、数日かけて2.5R以上の値幅を狙います。

1Rで部分利食いし、残りはスイング構造に沿ってトレールします。取引頻度の低さ（1ペアあたり月3〜8回）は設計仕様です。

設定・インストール方法

  1. 1対応ペアのH4チャートに適用。
  2. 2既定値は0.01ロット刻みの300ドル口座から対応。
  3. 3週末の窓を避けたい場合は金曜クローズフィルターを設定。
  4. 4ポジション確認は1日1回で十分。常時監視は不要。

推奨VPS: Any stable VPS; latency not critical
